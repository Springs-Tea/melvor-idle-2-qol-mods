[size=5][b]Kills in Combat[/b][/size]
Shows how many times you have killed the enemy you are fighting, in a small tag next to its name on the combat screen.

The number is the game's own statistic, so it is right after offline progress too.

[size=4][b]Install[/b][/size]
[list=1]
[*]Install the [url=https://www.nexusmods.com/melvoridle2/mods/2]Melvor Mod Loader[/url] (0.1.3 or newer).
[*]Extract this zip into the game folder: Steam > Melvor Idle 2 > Manage > Browse local files. The file ends up as [font=Courier New]mods\KillsInCombat\KillsInCombat.dll[/font].
[*]Start the game.
[/list]
[size=4][b]Uninstall[/b][/size]
Delete the folder [font=Courier New]mods\KillsInCombat[/font]. Nothing in your save is changed.

[size=4][b]Good to know[/b][/size]
Tested on game version 0.11.6-alpha.1 with Melvor Mod Loader 0.1.3. The game is in early access: an update can break the mod until it is rebuilt.
It uses the game's own textures, fonts and colours, so it looks like part of the game.
