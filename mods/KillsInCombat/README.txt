KILLS IN COMBAT 0.1.0
for Melvor Idle 2 (tested on 0.11.6-alpha.1), needs Melvor Mod Loader

Shows how many times you have killed the enemy you are fighting, in a small tag next to its name
on the combat screen. The number is the game's own statistic, so it is right after offline
progress too.

INSTALL
  Extract this zip into the game folder (Steam > Melvor Idle 2 > Manage > Browse local files),
  so that the file ends up as  mods\KillsInCombat\KillsInCombat.dll

UNINSTALL
  Delete the folder mods\KillsInCombat

Nothing in your save is changed.
