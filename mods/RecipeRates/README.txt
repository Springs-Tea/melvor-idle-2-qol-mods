RECIPE RATES 0.1.0
for Melvor Idle 2 (tested on 0.11.6-alpha.1), needs Melvor Mod Loader

Which recipe gives more XP per hour: the one that takes 60 seconds for 10 XP, or the one that
takes 20 seconds for 3? This shows it before you make anything.

  - In a skill's recipe list, every recipe shows its XP per hour under its XP tag. The best one
    in the list is gold.
  - Hover the XP tag for the whole hour: XP, the items made, the items used, what the products
    sell for, how long one takes, and how long the materials in your bank will last.

Works for Smithing, Crafting, Fletching, Runecrafting, Beastcrafting, Cooking, Firemaking and
Herblore.

The numbers come from the game's own values, so every bonus you have (equipment, potions,
mastery...) is in them. Chances count as their long-run average: doubling, preservation,
skipped steps, and failed attempts in Cooking. It is an estimate, not a promise.

INSTALL
  Extract this zip into the game folder (Steam > Melvor Idle 2 > Manage > Browse local files),
  so that the file ends up as  mods\RecipeRates\RecipeRates.dll

UNINSTALL
  Delete the folder mods\RecipeRates

Nothing in your save is changed.
