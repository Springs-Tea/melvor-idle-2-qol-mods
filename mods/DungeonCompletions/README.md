> How many times have I cleared this dungeon?

Shows how many times you have completed each dungeon, in a small tag next to the dungeon's name:

- on every dungeon in the combat areas menu,
- on the panel of the dungeon that is selected there.

A dungeon you have never finished shows `0`. Ordinary combat areas get no tag. The number is the game's own
statistic.

The tag looks like the one of [Kills in Combat](../KillsInCombat):

![The same kind of tag](../../docs/img/kills-in-combat.png)

## Install

1. Install the [Melvor Mod Loader](https://www.nexusmods.com/melvoridle2/mods/2).
2. Extract the mod's zip into the game folder, so the file ends up as
   `mods\DungeonCompletions\DungeonCompletions.dll`.

To remove it, delete `mods\DungeonCompletions`. Your save is never changed.
