DUNGEON COMPLETIONS 0.1.0
for Melvor Idle 2 (tested on 0.11.6-alpha.1), needs Melvor Mod Loader

Shows how many times you have completed each dungeon, in a small tag next to the dungeon's name
in the combat areas menu and on the panel of the selected dungeon. The number is the game's own
statistic.

INSTALL
  Extract this zip into the game folder (Steam > Melvor Idle 2 > Manage > Browse local files),
  so that the file ends up as  mods\DungeonCompletions\DungeonCompletions.dll

UNINSTALL
  Delete the folder mods\DungeonCompletions

Nothing in your save is changed.
